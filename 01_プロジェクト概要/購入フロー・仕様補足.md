# 購入フロー仕様補足

## 1. この文書の目的

テスト計画を作成するために、
購入フローの前提となる最小限の仕様を整理する。

## 2. 購入フロー

商品閲覧
→ カート追加
→ ログイン
→ 配送先決定
→ 支払方法選択
→ 注文内容確認
→ 注文確定
→ 注文完了

## 3. 決定済みの仕様

### 支払方法

- モック決済を使用する
- 外部決済サービスとの実接続は行わない

## 4. 検討中の仕様

### 配送先

- 登録済み住所を使用するか
- 新しい住所を入力可能にするか
- 両方から選択可能にするか

### 注文完了

- 注文完了画面に何を表示するか
- 注文履歴まで今回の確認対象に含めるか
