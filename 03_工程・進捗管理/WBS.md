# テスト工程 WBS v0.1

## 1. 仕様確認・不明点整理（1〜2日目）

| WBS | 作業               |
| --- | ---------------- |
| 1.1 | 関連資料・テスト対象範囲の確認  |
| 1.2 | 不明点・未決定事項の抽出と記録  |
| 1.3 | 仕様・設計担当への確認      |
| 1.4 | 回答内容の反映・仕様確認完了判定 |

## 管理上の補足

* WBSでは、工程として進捗を管理したい作業単位を扱う。
* 「回答待ち」「修正待ち」「再テスト待ち」などの状態は、課題管理表や不具合管理で追跡する。
* 不具合票への証跡添付やコメント記入など、個々の作業手順まではWBSに分解しない。
* テストデータは、テストケース作成後に必要なデータを具体化する。
* 次工程へ進む際は、テスト計画書で定めた開始基準・終了基準を確認する。
