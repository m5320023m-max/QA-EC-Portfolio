## プロジェクトの前提

本プロジェクトは、ハンドメイド雑貨を販売するECサイトの
 **「新規開発および初回リリース」** を想定する。

初回リリースでは、利用者が商品を閲覧し、
カートに追加した商品を購入できる基本的なEC機能を提供する。

サイトの利用目的→一般利用者がハンドメイド雑貨を閲覧し、購入できるECサイト。

利用者→会員ユーザー,非ログインユーザー

## 利用の流れ

<aside>

#### 【共通の流れ】

商品を探す
→ 商品詳細を確認する
→ カートに追加する
→ カート内容を確認する

#### 【ログイン済みの場合】

購入手続きへ進む
→ 配送先を確認する
→ 注文内容を確認する
→ 注文を確定する
→ 注文完了を確認する
→ 注文履歴で商品・個数・金額を確認する

#### 【未ログインの場合】

購入手続きへ進む
→ ログインまたは会員登録を求められる
→ ログインまたは会員登録を行う
→ 購入手続きへ戻る
→ 注文を確定する

</aside>

## 対象機能

<aside>

## 対象範囲を記載する際のルール

- 対象機能一覧を、今回テストする内容の正本とする。
- テストする内容は、必ず対象機能一覧に明記する。
- 対象外機能一覧には、テストしない内容のみを書く。
- 「対象外。ただし○○は対象」のように、対象と対象外を同じ欄へ混在させない。
- 境界が分かりにくい場合は、対象と対象外を対になる形で明記する。

例：

対象：
支払方法の選択、モック決済の結果に応じた画面遷移

対象外：
外部決済サービスとのAPI接続、実際のカード請求

</aside>

| 機能 | 概要 | ログイン要否 |
| --- | --- | --- |
| 商品閲覧・検索 | 商品一覧、検索、商品詳細を確認する | 不要 |
| カート | 商品の追加、数量変更、削除、内容確認を行う | 不要 |
| 会員登録 | 新しい会員情報を登録する | 不要 |
| ログイン・ログアウト | 会員の認証状態を管理する | ログインは不要、ログアウトは必要 |
| 購入手続き | 配送先の入力・確認、支払方法の選択（モック決済）、注文内容の確認を行う | 必要 |
| 注文 | 注文を確定し、完了結果を表示する | 必要 |
| 注文履歴 | 確定した注文の内容を確認する | 必要 |

## 対象外機能

今回のQAポートフォリオでは、以下の機能を対象外とする。

| 対象外機能 | 対象外とする理由 |
| --- | --- |
| 管理者機能 | 利用者側の購入フローを優先するため |
|  外部決済サービスとの実接続 | APIキーや外部環境が必要となり、外部サービス側の仕様まで検証範囲が広がるため |
| ポイント・クーポン | 価格計算の仕様が複雑になり、範囲が広がるため |
| 商品レビュー | 購入フローの確認を優先するため |
| お気に入り | 購入に必須ではないため |
| 返品・キャンセル | 注文後の業務フローまで範囲が広がるため |
| 配送状況の追跡 | 配送業者との外部連携が必要になるため |
| 多言語・多通貨対応 | 初期版は日本国内向けとして扱うため |
