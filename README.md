# ECサイト QAポートフォリオ
ECサイトを題材に、QAリーダーとしてテスト全体を計画・管理し、
品質評価とリリース判断まで行うポートフォリオです。
将来的には、テスト自動化とAIを利用した品質分析まで組み込みます。

## 目的
- テスト計画からリリース判断までの流れを経験する
- QAリーダーが使用する成果物を作成する
- 実務経験を体系化する
- 品質管理、自動化、AI活用を一つの題材でつなげる
